# 谢三宾小记

辑存明末清初鄞县谢三宾（1593–1672，字象三，号塞翁，一作寒翁）的作品文本与传记资料。

## 小传

谢三宾，字象三，号塞翁（一作寒翁、研北），浙江鄞县（今宁波）人。天启五年（1625）进士，钱谦益典试浙江所取门生。初知嘉定县，均田均役、疏浚吴淞江，擢陕西道御史。崇祯五年（1632）巡按山东监军，平登莱之乱，叙功进太仆寺少卿，丁忧归。明亡后两度降清，告密宁波义军，为乡评所薄。能画山水，与董其昌、李流芳、程嘉燧等究论画理，载《明画录》。晚年居月湖谢家巷"天赐园"，藏书甚富。卒于康熙十一年（1672）。

## 说明

《一笑堂诗集》八百二十余首诗目前没有公开的完整电子文本，本仓库辑存散见诗作与传记、史料文字。刻本影像见国家图书馆·中华古籍资源库（康熙刻本两册，需注册登录在线阅览）；整理本为宁波图书馆编《一笑堂诗集》点校本（宁波出版社 2021 年版，ISBN 978-7-5526-4153-0）。

所辑文字均录自公开电子本，未经刻本核校，研究引用请核对原书。
