# 恩师谬徒谢三宾先生小辑

辑存明末清初鄞县谢三宾先生（1593–1672，字象三，号塞翁）的作品文本与传记资料。

## 小传

谢三宾，字象三，号塞翁，浙江鄞县（今宁波）人。天启五年（1625）进士，钱谦益典试浙江所取门生。初知嘉定县，均田均役、疏浚吴淞江，擢陕西道御史。崇祯五年（1632）巡按山东监军，平登莱之乱，叙功进太仆寺少卿，丁忧归。明亡后两度降清，告密宁波义军，为乡评所薄。能画山水，与董其昌、李流芳、程嘉燧等究论画理，载《明画录》。晚年居月湖谢家巷"天赐园"，藏书甚富。卒于康熙十一年（1672）。
